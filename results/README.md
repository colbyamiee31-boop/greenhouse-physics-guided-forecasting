# Results directory

The public GitHub repository should contain lightweight reference CSV outputs and documentation.
Large prediction arrays and complete archived outputs are distributed in the DOI archive.

Key manuscript outputs include:
- five-seed mean ± SD,
- nested seed/day bootstrap + Wilcoxon-Holm results,
- multi-timescale grey-box diagnostics,
- gradient-conflict diagnostics,
- NASA boundary-forcing sensitivity.

See `docs/MANUSCRIPT_RESULT_MAP.csv`.
