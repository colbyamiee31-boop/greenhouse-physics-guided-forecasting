# Public release checklist

Before creating a public GitHub/Zenodo/OSF release:

- [x] Correct NASA forcing coordinate locked to 40.54°N, 81.30°E.
- [x] Obsolete v2 NASA-dependent results excluded from the canonical workflow.
- [x] Canonical processed v3 data included.
- [x] Exact multi-timescale physics result verified.
- [x] Exact five-seed statistical conclusions recomputed from archived predictions.
- [x] Independent full-training smoke test reproduces the central prediction–physics trade-off.
- [x] NASA grey-box stress-test magnitudes reproduced.
- [x] `run_all.py --mode analysis-only` verified.
- [ ] Authors select an explicit software/data license.
- [ ] Confirm institutional/data-sharing permissions for public release.
- [ ] Create permanent DOI/repository URL.
- [ ] Replace manuscript Data Availability text with the DOI/repository URL.
